# chatSummary

Purpose: keep a durable, copy/paste-ready handoff snapshot for starting a new chat when context is limited.

## Files
- `LATEST.md`
  - Always contains the most up-to-date status summary.
  - Use this as the seed context for a new chat.

- `YYYY-MM-DD_status.md`
  - Dated snapshots for historical tracking.

## Updating
1) Create a new dated file (copy the current `LATEST.md` and adjust as needed).
2) Update `LATEST.md` to match the new dated snapshot.
