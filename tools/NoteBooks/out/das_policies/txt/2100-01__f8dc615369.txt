I. Purpose 
This policy addresses the use, management, and control of passwords used to access Ohio 
Department of Administrative Services (DAS) -Managed System Assets. The first occurrence of a  
defined term in the policy body outside of a title or heading is in bold, italic type, and is hyperlinked 
to the definition in Section IV. 
 
II. Scope 
The scope of this policy includes all user accounts (or any forms of access that support or require  
a password) on any DAS-Managed System Assets. 
 
III. Policy 
DAS is issuing this policy to ensure compliance with related state policies and to protect DAS-
Managed System Assets. DAS IT systems managers shall ensure that passwords for DAS-Managed 
System Assets adhere to the following requirements: 
 
A. Password Standard s: The use, management, and control of passwords that are used to 
access DAS-Managed System Assets shall conform to the requirements outlined in DAS -ITS-
2100-01-A, "Password Standard for Organizational Users," and DAS-ITS-2100-01-B, "Password 
Standard for Non-Organizational Users." 
 
B. Compromised Passwords:  Immediately deactivate user accounts associated with 
compromised passwords, maliciously or by accident. All instances of compromised 
passwords must be immediately reported by contacting the Customer Service Center at 
CSC@ohio.gov, 614-644-6860 or 877-644-6860.

C. Browser-Based Save Password Configuration Setting: Save Password Options shall not be 
allowed. If an information system's browser-based save password feature cannot be disabled, 
users shall be instructed not to use that option. 
 
D. Legacy or Non-stan dard Systems: DAS IT systems managers shall id entify systems that are 
unable to support User IDs, passwo rds, or other security measures for access to 
administrative level services and develop procedures to offset this risk. 
 
1. DAS IT systems managers shall ensure that administrators of such systems are both 
aware of the risk and trained on how to safeguard such systems. 
2. Upgrades to these systems shall involve the implementation of security measures, 
including user IDs and passwords, as outlined in this policy,  and defined in DAS IT 
Standard DAS-ITS-2100-01-A, “Password Standard for Organizational Users,” and DAS IT 
Standard DAS-ITS-2100-01-B, “Password Standard for Non-Organizational Users.” 
 
E. Password Masking: Pass
 words shall not be displayed to the user in their entirety; passwords 
shall be masked or obscured from view when entered. It is permissible to program systems to 
briefly display individual keystrokes. 
 
F. Default Passwords : Def ault application and system passwords shall be reset before the 
deployment of any system or application. 
 
IV. Defin
itions 
  
A. DAS-Managed System Asset . Information, hardware, software  and services required to 
support state business, and identified during the risk assessment process as assets that need 
to be protected. Primary responsibility for managing these system assets may be assigned to 
DAS OIT personnel or other outside entities. 
B. Save Password Option. An option on some systems that, when enabled, allows the user the 
choice of whether to have the user password memorized by the system so that it will not need 
to be re-entered upon subsequent access. 
C. Users. An individual or (system) process authorized to access an information system.
